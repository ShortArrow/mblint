# ADR-0011: ボードのソケットは、ルートより低い世代を書ける

[English](0011-board-sockets-cap-their-generation.md)

- 状態: 採用

## 文脈

ボードのソケットは、行き着くルートの PCIe の世代を受け継いでいた。MSI MAG X870E TOMAHAWK WIFI では、X870E チップセットが PCI_E3、M2_3、M2_4 に PCIe 4.0 を供給するが、同じチップセットの下の PCI_E2 は PCIe 3.0 x1 でしか動かない。このボードを書くには、その一つのスロットのために、チップセットのルートを架空にもう一つ作るしかなかった。アダプタの `pcie_slot` は、すでに自分の `generation` を持っている。

## 決定

- ボードの `pcie_slot` と `m2_slot` は、省略できる `generation` を持つ。
- Pass 4 は、ボードのソケットの世代を、その `generation` とルートの世代の小さい方とする。`generation` の無いソケットは、ルートの世代を持つ。

## 理由

- 遅い世代はスロットの配線の性質なので、スロットに書くのが適切である。
- 小さい方をとれば、ソケットに何が書かれていても、供給するルートより速く評価されることは無い。
- フィールドの名前と意味は、アダプタの `pcie_slot` と同じである。

## 採らなかった案

- 遅いスロットのためにルートをもう一つ作る: ルートはレーンを供給するものであり、チップセットを二つのルートに分けると、どのソケットがそれを共有しているかが見えなくなる。
- ボードのソケットで `generation` を必須にする: ほとんどのソケットはルートの世代で動く。すべてのソケットにそれを繰り返すと、両者が食い違うおそれが生じる。
