# ADR-0017: MCP サーバーは、Web シミュレーターが成熟するまで待つ

[English](0017-mcp-server-waits-for-the-web-simulator.md)

- 状態: 採用

## 文脈

PRD は、Phase 2 で CLI と並べて、LLM クライアントが stdio 経由でトポロジーを探索し構成を診断する MCP サーバー `mblint mcp` を計画していた。`mblint check` と `mblint lint` は今、`--json` を付けるとレポートを JSON で出力し、診断は仕様の名前のコードで表され、終了ステータスはエラーと警告を区別するので、コマンドを実行できるエージェントはすでに mblint を使える。Phase 3 の Web シミュレーターには、まだ着手していない。

## 決定

- ロードマップの Phase 2 は CLI だけとする。
- MCP サーバーは新しい最後のフェーズに移し、Web シミュレーターが成熟してから取りかかる。

## 理由

- それまでのあいだ、エージェントは CLI の JSON レポートで用が足りるが、人には Web シミュレーターができるまで CLI のほかにインターフェースが無い。
- MCP サーバーを後に作れば、Wasm ビルドが形づくったあとのコアのインターフェースに沿わせられ、今二つ目のインターフェースを固めずに済む。

## 採らなかった案

- MCP サーバーを今、Phase 2 で作る案：CLI がすでに要求を満たしているフロントエンドのために、Web シミュレーターが遅れる。
- MCP サーバーをやめる案：コマンドを実行できない MCP クライアントは、mblint を使う手段を持たないままになる。
