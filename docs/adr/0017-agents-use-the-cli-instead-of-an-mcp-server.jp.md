# ADR-0017: LLM エージェントは CLI を使い、mblint は MCP サーバーを持たない

[English](0017-agents-use-the-cli-instead-of-an-mcp-server.md)

- 状態: 採用

## 文脈

PRD は、Phase 2 で CLI と並べて、LLM クライアントが stdio 経由でトポロジーを探索し構成を診断する MCP サーバー `mblint mcp` を計画していた。`mblint check` と `mblint lint` は今、`--json` を付けるとレポートを JSON で出力し、診断は仕様の名前のコードで表され、終了ステータスはエラーと警告を区別する。コマンドを実行できるエージェントは、それらを直接呼べる。

## 決定

- mblint は MCP サーバーを持たない。LLM エージェントは `--json` を付けて CLI を使う。
- ロードマップの Phase 2 は CLI だけとする。

## 理由

- CLI の JSON レポートは、MCP のツールが返すはずのものをすでにすべて含むので、サーバーはエージェントに新しいものを与えず、歩調を合わせ続ける二つ目のインターフェースを増やすだけである。
- フロントエンドが一つ減り、コアの利用者は CLI と Wasm ビルドの二つになる。

## 採らなかった案

- `check` と `lint` を包む MCP サーバー：CLI のインターフェースを重複させ、独自のプロトコルの依存、テスト、文書を必要とする。
