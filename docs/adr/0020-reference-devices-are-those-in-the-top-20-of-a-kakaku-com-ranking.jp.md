# ADR-0020: デバイスは、価格.com のランキングでそのカテゴリの 20 位以内に入ったことがあるときにデータへ加える

[English](0020-reference-devices-are-those-in-the-top-20-of-a-kakaku-com-ranking.md)

- 状態: 採用

## 文脈

Web シミュレーターは、`data/devices/` のデバイスを、rig を組むパーツとして一覧にする。そこにはまだ一つもデバイスが記述されていなかった。すべての製品を記述することはできず、その意味もないので、データには多くの人が使うデバイスだけを置き、それ以外は使う人がページに読み込む。どのデバイスが当てはまるかは、変更をレビューする人が確かめられなければならない。製品ごとの販売数は公開されていない。Mindfactory の週ごとの販売台数はドイツの 1 店舗のもので、第三者が集めている。BCN AWARD はカテゴリごとの 1 位のメーカーを示し、製品ではない。Steam ハードウェア調査は使われている GPU チップの割合で、製品の割合ではない。Keepa の Amazon の売れ筋順位の推移は有料である。Jon Peddie Research や DigiTimes の報告による出荷台数は、メーカーごとか市場全体の数字である。

## 決定

- デバイスは、その製品が価格.com の「人気売れ筋ランキング」で、追加する日か、Wayback Machine に保存されたそのランキングのどれかで、そのカテゴリの 20 位以内にあるとき、`data/devices/` に加える。
- 確かめるのは、追加を求められたデバイス 1 件についてである。保存されたランキングをまとめて集めることはしない。
- ファイルには、読んだランキングを日付か保存されたページの URL で示し、カテゴリと順位とともにコメントで残す。
- 一度加えたデバイスは、あとで順位が下がっても残す。

## 理由

- 順位と、それを読んだ日なら、変更をレビューする人が誰でも確かめられる。保存されたページの URL は、同じページを指し続ける。
- Wayback Machine は、グラフィックボードとマザーボードのランキングを、2008 年 6 月からそれぞれ 97 か月分と 99 か月分保存している。そのため、追加より前によく売れた製品も当てはまりうる。
- 価格.com は、PC パーツをカテゴリごとに順位付けしている。
- ランキングから外れた製品も、人が検査する PC にはまだ入っているので、外れたことは消す理由にならない。

## 採らなかった案

- 販売数や出荷台数：製品ごとには公開されていない。
- Steam ハードウェア調査：グラフィックボードだけで、GPU チップ単位である。デバイスファイルは、長さや厚みを持つ一つの製品を記述する。
- Keepa の売れ筋順位の推移：有料の契約が無ければ確かめられない。
- グッドデザイン賞などのデザイン賞：使われ方ではなくデザインを評価し、PC パーツの受賞はほとんど無い。

## 結果

- Wayback Machine が保存しなかった月にだけよく売れた製品は、当てはまることを示せない。
- まとめて集めないのは、短い時間に Wayback Machine へ多くの要求を送ることになり、またデバイスごとに値を仕様と手で照らし合わせる必要があるからである。
- 主に日本以外で売られるデバイスや、キャプチャーカードやシリアルカードのような用途の限られたデバイスは、ほとんど加わらない。それらを使う人は、ページに読み込む。
- 価格.com プロダクトアワードの受賞製品も当てはまるかどうかは、のちの判断に残す。
