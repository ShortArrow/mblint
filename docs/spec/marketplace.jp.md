# マーケットプレイス

[English](marketplace.md)

マーケットプレイスは、GitHub で公開された rig を一覧にし、それぞれを Web シミュレーターで開けるページである。シミュレーターとは別のサイトで、marketplace.mblint.shortarrow.jp にある。

## 一覧

GitHub の公開リポジトリは、トピック `mblint-rig` を付けると一覧に載る。公開する人がすることはトピックを付けることだけで、申請も審査もない。リポジトリは、トピックを外したとき、非公開になったとき、削除されたとき、マーケットプレイスの除外リストに名指されたときに一覧から外れる。

各リポジトリは、`<owner>/<repo>`、説明、スター数、最後に push された日付とともに示す。リポジトリ名は GitHub 上のそのリポジトリへのリンクである。またボタンで、シミュレーターを `https://mblint.shortarrow.jp/?github=<owner>/<repo>` で開く。このアドレスは、シミュレーターのアドレスと同じように、既定のブランチのルートを読み込む。

リポジトリはスター数の多い順に並ぶ。入力欄に文字を入れると、`<owner>/<repo>` か説明にその文字を含むものだけに絞る。大文字と小文字は区別しない。

マーケットプレイスが示す内容は、GitHub より最大 1 時間遅れる。マーケットプレイスはリポジトリのファイルを読まないので、一覧のリポジトリが、シミュレーターで読み込める rig を持たないこともある。その場合は、開いたときにシミュレーターがそう示す。

## 公開

ページには「Publish your rig」の節があり、次の手順を並べる。

1. GitHub に公開リポジトリを作る。たとえば、ひな形の ShortArrow/mblint-rigs から作る。
2. シミュレーターから書き出した rig のファイルを、デフォルトブランチのルートに置く。
3. リポジトリにトピック `mblint-rig` を付ける。GitHub のリポジトリのページで About の横の歯車を選び、Topics の欄に入力して Save changes を選ぶ。または `gh repo edit <owner>/<repo> --add-topic mblint-rig` を実行する。
4. マーケットプレイスに載るまで、最大 1 時間待つ。

ひな形の名前は、GitHub にあるひな形のリポジトリ https://github.com/ShortArrow/mblint-rigs へのリンクにする。

## 見た目

ページには、シミュレーターと同じ形のヘッダーがあり、マーケットプレイスの名前と、mblint.shortarrow.jp のシミュレーターへ戻るリンクを出す。各リポジトリはカードとして並ぶ。色はシミュレーターと同じ。書体もシミュレーターと同じ Inter と JetBrains Mono で、シミュレーターと同じく Google Fonts から読み込む。テーマはシステムのライトかダークに従う。スクリプトを持たないので、テーマの切り替えはない。シミュレーターのサイトからは何も読み込まない。リポジトリの名前や説明がどれほど長くても、横にはスクロールしない。一覧の下には、シミュレーターのプライバシーのページ https://mblint.shortarrow.jp/privacy.html へのリンクを置く。

## ビルド

マーケットプレイスは Cloudflare Worker である。公開データを読む権限だけを持つトークンでサインインして、GitHub の検索 API にトピックの付いたリポジトリを問い合わせ、その答えを 1 時間保持する。そのため、訪問者のブラウザは GitHub に問い合わせない。GitHub に届かないときは、最後に保持した答えを、その古さを添えて返す。保持した答えを読めないときは、混雑しているので後で試すよう示し、GitHub には問い合わせない。答えを 1 つも保持しておらず、GitHub にも届かないときは、GitHub に届かないので後で試すよう示す。
