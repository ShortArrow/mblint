# mb-lint

[English](../README.md)

mblint は、PC を組み立てる前に、構成をマザーボードと突き合わせて検証するツールです。ボードを、レーン供給源・Mux・プロトコルブリッジ・ソケットから成る一つの有向グラフとしてモデル化し、カードや周辺機器の組み合わせが実際にどうなるかを報告します。報告するのは、ぶつかるスロット、分割・無効化されるレーン、トンネリングで失われる帯域、そして IOMMU グループを共有しているため単体では VM にパススルーできないデバイスです。

ハードウェアは宣言的な TOML で記述します。同じデータを、人と LLM エージェント向けの CLI と、将来の静的 Web シミュレーターの両方で使います。

## 状況

開発初期で、[ロードマップ](prd.jp.md#8-ロードマップ)の Phase 1 にあたります。コアライブラリ `mblint-core` は現在、PCIe bifurcation の mode 選択と、ルートごとのレーン収支の検査ができます。CLI はまだありません。
