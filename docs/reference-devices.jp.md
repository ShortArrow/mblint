# 基準デバイス

[English](reference-devices.md)

基準デバイスは、`data/devices/` に記述した実在の製品である。Web シミュレーターは、これらを rig を組むパーツとして一覧にする。ここに記述されていないデバイスは、使う人がページに読み込む。

## 記述するデバイス

その製品が価格.com の「人気売れ筋ランキング」で、追加する日か、Wayback Machine に保存されたそのランキングのどれかで、そのカテゴリの 20 位以内にあるとき、記述する。確かめるのは、追加を求められたデバイス 1 件についてである。一度記述したデバイスは、あとで順位が下がっても残す。

まだ記述したデバイスは無い。

## 出典

- ファイルの先頭のコメントに、読んだランキングを日付か保存されたページの URL（`https://web.archive.org/web/<日時>/…`）で示し、カテゴリと順位とともに残す。
- 値はすべて、その製品のメーカーの仕様から取り、その URL をファイルの先頭のコメントに書く。
- スキーマが必須とする値を仕様が述べていない製品は、記述しない。
