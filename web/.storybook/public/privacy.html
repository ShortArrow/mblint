mblint Storybook

Privacy

This page covers mblint's Storybook at storybook.mblint.shortarrow.jp, which shows the simulator's parts one at a time. It does not ask you to sign in. It sets no cookie itself; the one Cloudflare sets is described below.

Cloudflare Web Analytics

The Storybook is served by Cloudflare, which adds the script of Cloudflare Web Analytics to its pages. For each visit, the script reports the page's address, the site that linked to it, your country, browser, operating system and type of device, and how long the page took to load. The list of what it records is Cloudflare's.

Cloudflare states that Web Analytics uses no state kept in your browser, such as a cookie or local storage, to collect these figures, and that Cloudflare does not fingerprint visitors by their IP address, their browser's User-Agent or any other data for the purpose of displaying analytics. See Cloudflare Web Analytics.

Cloudflare's check for automated browsers

Cloudflare also adds the script of its JavaScript Detections to the Storybook's pages, to tell browsers run by software from those used by people. When the script runs, Cloudflare sets a cookie named cf_clearance in your browser, holding the outcome of that check.

The outcome blocks or challenges a visit only through a rule that the site sets up to act on it. The Storybook has no such rule, so the cookie stops nobody. See JavaScript Detections.

What Storybook keeps in your browser

Storybook keeps how its screen is laid out, its keyboard shortcuts and the stories you viewed last in your browser's local storage and session storage. It sends none of this anywhere.
